# Android App for Universal Robots

An **Android application for monitoring and controlling an industrial robotic process** developed as part of my Bachelor's thesis on human-robot interaction with Universal Robots.

The application provides a visual interface through which an operator can **monitor the execution of an industrial process and interact with the robot while the process is running**.

It complements the Polyscope URCap developed in the same thesis: while the URCap is used to configure and program the process, the Android application focuses on its runtime monitoring and control.

The project explores the use of a mobile interface as an additional interaction layer between human operators and industrial robots.
